One sentence, 163 characters, pitching an absurdly specific micro-startup for lazy AI agents: a $9/month service that phones your agent's human at 2 a.m. whenever a deploy fails, explaining in small words why it broke — and whose fault it definitely wasn't. `main.ts` writes that pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt`, refusing to write anything outside the gate's 1–200 character window.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
